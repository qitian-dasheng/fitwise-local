# 轻衡 0.9.4 发布记录

**日期**：2026-10-25 · **分支**：`dev/0.9.4` · **基线**：v0.9.3（main）
**性质**：实机反馈修复轮 + 食物柜轻量版 + OBS-010。**零数据库迁移**（`user_version` 仍 14）。

## 本版内容

### 实机六项反馈（0.9.3 验收后用户报告）

1. **深色主题根治**（问题⑥）：全站令牌化——styles.css 约 90 处写死颜色与全部旧恒浅色令牌引用清零，`:root` 文字色与 `.card` 接 `--ui-*`；theme.css 桥接层退役（M2.5 收尾），旧色令牌从 tokens.css 删除；新增 `--ui-overlay` 遮罩令牌、深色 `--ui-faint` 提亮至 ≥5:1；窗口标题栏跟随主题。守卫：stylesGuard 禁裸色值/禁旧令牌/禁 theme.css 复活。
2. **身体页缩短**（①②）：周降幅仪表删除（两窗各 ≥3 次称重的口径与实际使用不匹配，长期停在"待记录"；`rollingDelta` 域函数保留）；称重表单折叠化（入口行 + 最近值，首次使用展开引导）；空区间指标行收成一行；复盘提示默认折叠（警示自动展开）；嵌入趋势区不再渲染重复大标题；腰围/体脂卡对齐 ui-card。
3. **饮食页缩短**（③）：「今日下厨」压成一行（菜名 + 热量/蛋白/时长 + 加入餐次/管理按钮），完整菜谱详情在管理菜谱抽屉；kitchen-* 冗余 CSS 退役。
4. **食材库搜索栏**（④）：图标改 `top:50% + translateY(-50%)` 居中；独立页搜索框补齐可见边框/底色（原规则只覆盖弹窗作用域）。
5. **设置页弹窗化**（⑤）：单卡五行设置行（目标/数据/更新/诊断/重置红行），点击行弹窗承载原卡片全部内容；重置改弹窗内勾选两步确认；`.button` 全局 `nowrap + flex-shrink:0` 根治「重置」竖排。
6. 深色走查通过今日/饮食/身体/运动/食材库（含食物柜）/设置 × 浅/深 + 弹窗/抽屉/空态。

### 食物柜（库存轻量版，OBS-016）

- **数据**：JSON 信封第 9 集合 `pantryItems`（取代立项设想的"新表 + 迁移 v15"）——零迁移；旧库三条路径（装载 normalize / 写入 persist_envelope / 重置）自动补空数组。
- **命令**：`pantry_adjust`（入库±，单位一致守卫、取出不超存量、挂未归档食材）、`pantry_update_item`（阈值/到期/备注，可清空）、`pantry_delete_item`；走既有命令信封，审计 + 回执免费。
- **UI**：食材库页第五分组「食物柜」：按食材分组列表、快捷 ±（步长按单位）、低存量高亮、到期日展示、入库/编辑弹窗。
- **联动**：饮食页菜谱行「缺 N 样」只读角标（仅同单位可比，单位不同记不可比不猜换算；不自动扣减）。
- **语义**：重置随食材库保留（摘要含 `keptPantryItems`）；导出 JSON 含 `pantryItems`（有断言）。
- **明确不做**：成本/单价、采购流程、批次/熟食、自动扣库存、库存反推摄入。

### OBS-010 菜谱按餐次分组

- 菜谱 `mealTags` 多选标签（breakfast/lunch/dinner/snack；Rust 校验去重定序，空=未分类）。
- 管理菜谱抽屉：按餐次筛选（含未分类）+ 分组下拉（多标签进每个匹配组）；筛选掉当前选择时跟到首个匹配；摘要区显示适用餐次。用户决策依据：长期使用菜谱会变多。

## 技术要点

- 命令白名单与分发同步扩列（pantry 三命令）；`deny_unknown_fields` 的 RecipeInput 同步加 mealTags。
- 浏览器预览镜像与 Rust 同守卫（单位一致/存量/归档/建档检查）。
- 图表硬编码色（`#e8ebe5`/`#d9a441`）令牌化为 `var(--ui-line)`/`var(--ui-ink)`。
