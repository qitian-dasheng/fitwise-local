## 流程承诺（每版不变）

1. 开发迭代 → 侧边栏浏览器用户复查 → 通过后才构建安装包
2. C 级门禁全绿（vitest / tsc / clippy / cargo test / fmt）+ 双主题截图自验
3. 实机验收通过 → 用户确认发布 → 合并 main + tag + Release 三件套
4. 零数据风险：能不迁移就不迁移；要迁移走完整门闩 + 升级前自动备份
