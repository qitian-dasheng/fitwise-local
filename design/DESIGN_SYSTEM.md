# 轻衡设计系统 0.5

> **数值不在本文档里。** 所有颜色、字号、间距、圆角的实际值只存在于 `src/styles/tokens.css`（唯一真源）。本文档只写**规则、用法与禁止项**。
> 想改视觉：改 tokens.css → 打开 `design/prototype/index.html` 看效果 → 跑设计守卫。
> 想让文档与代码一致：不要往这里抄色值。

样张：`design/prototype/index.html`（今日 / 饮食 / 身体三页，浏览器直接打开）。

---

## 1. 五条原则

1. **一个强调色**。全站只有 `--accent` 一种彩色，且**只作填充**。颜色用来指示"当前/可操作"，不用来装饰。
2. **用描边和底色分层，不用阴影**。层级靠 `--line` 0.5px 描边 + `--surface` 的白与 `--surface-sunken` 的灰，禁止 `box-shadow`。
3. **数字是第一公民**。所有数值用等宽数字（`tabular-nums`），永远右对齐，小数点对齐；单位用 `--ink-400` 小一号。
4. **字不缩小，只减墨**。最小 11px。需要更弱时换 `--ink-400` / `--ink-300`，不要缩到 10px、9px。
5. **空态给信息，不给破折号**。空格子写"库里有 400 g 里脊"或"不饿就不用记"，不铺一排 `—`。

## 2. 色彩

### 角色

| 令牌 | 用途 | 禁止 |
| --- | --- | --- |
| `--ink-900` | 标题、关键数值、当前导航项底 | 用于大段正文（太重） |
| `--ink-700` | 正文默认 | — |
| `--ink-600` | 次要正文、表格单元 | — |
| `--ink-500` | 辅助说明、单位 | — |
| `--ink-400` | **正文下限**（对比 5:1），图表轴标签、提示 | 再浅就不可读 |
| `--ink-300` | 仅装饰：分隔点、禁用、图标描边 | **不可承载信息** |
| `--line` / `--line-soft` | 卡片描边 / 行分隔 | 不要用灰底代替描边 |
| `--surface` / `--surface-sunken` / `--surface-raise` | 卡片 / 页面底与表头 / 弹窗内区块 | 三层够了，不要再造第四层 |
| `--accent` | 主按钮底、选中态、进度条、图表"当前"柱 | **绝不作为文字色**（白底对比不足） |
| `--accent-ink` | 强调底上的文字 | — |
| `--accent-soft` | 选中行背景 | — |
| `--ok` `--warn` `--danger` `--info` | 仅状态语义，配 `-soft` 作底 | 不能当主题色使用 |

### 规则

- **强调色一屏最多三处**：主按钮、当前导航、当前数据点。超过三处就没有"强调"了。
- 状态色只出现在状态胶囊、错误提示、图表标注里；正文永不变色。
- 同一屏内语义色不超过两种同时出现。

## 3. 字体

- 字族：`--font-sans`（Noto Sans SC，SIL OFL，中英分开子集，随仓库提交）。数字与代码用 `--font-mono`。
- **只用三档字重**：`--fw-regular` 400（正文）、`--fw-medium` 500（标题、按钮、关键数值）、`--fw-strong` 600（页面主标题、品牌）。**没有 700**。

| 令牌 | 角色 | 行高 |
| --- | --- | --- |
| `--fs-40` | 首屏主数值，**一页最多一个** | 1 |
| `--fs-28` | 卡片内主数值 | 1 |
| `--fs-20` | 页面标题 `h1` | `--lh-tight` |
| `--fs-16` | 卡片标题、段落标题 `h2` | `--lh-snug` |
| `--fs-14` | **正文默认**、表格主内容、按钮、输入 | `--lh-body` |
| `--fs-13` | 行内次要信息：份量、单位、表格副行、文字按钮 | `--lh-snug` |
| `--fs-11` | 小标签、图表轴、胶囊 | `--lh-body` |

- **正文与小标签必须差两档**（14 vs 11），副行 13 居中。差一档会导致"内容"和"框的小标题"看起来一样大——这是最容易犯的错。

- 小标签（"今日摄入""蛋白 g"这类）用 `--fs-11` + `--tracking-label`；中文不用大写变形，只加字距。
- 数值必须 `font-variant-numeric: tabular-nums`，否则翻页时数字会左右跳。
- 一屏最多出现两级标题（`h1` + `h2`），不要 `h3` 再套 `h3`。

---

## 4. 间距、栅格与密度

- 所有间距取 `--sp-1`…`--sp-8`（4 的倍数）。**禁止 5px、7px、13px 这类非标值**。
- 页面左右留白 `--page-x`，内容最大宽 `--content-max` 居中；侧栏 `--nav-w`。
- 卡片内边距 `--card-p`；卡片之间 `--sp-4`；同卡内区块 `--sp-5`。
- 表格行高 `--row-h`；表格单元左右 `--sp-2`，首列不缩进、末列不缩进（贴齐卡片内边距）。
- 桌面优先：1440 与 1920 是主力，1366 不得横向滚动、不得文字挤压。

---

## 5. 形状与层级

- 圆角三档：`--r-sm`（输入、按钮、小卡）、`--r-md`（卡片、列表项）、`--r-lg`（弹窗）、`--r-pill`（胶囊、分段控件、进度条）。
- 描边统一 `--stroke`（0.5px）。**层级 = 描边 + 底色**，不用投影、不用模糊、不用渐变。
- 弹窗用遮罩 + 白底 + 0.5px 描边；切不要在弹窗上叠投影。

---

## 6. 组件规范（每个都必须有五态）

> 五态：**正常 / 悬停 / 焦点 / 禁用 / 加载**；有数据的组件另有**空态**与**错误态**。

### 按钮 `.btn`
- 变体：默认（白底描边）、`primary`（强调底）、`ink`（墨底，用于"确认类"而非"操作类"）、`ghost`（无底，仅文字）、`sm`（30px 高）。
- 一屏最多一个 `primary`。表单底部的主按钮占整行。
- 禁用：底色变 `--surface-sunken`、文字 `--ink-300`、`cursor: not-allowed`，**并说明为什么不能点**（见"更正原因必填"的教训）。
- 加载：文字换成"正在保存…"，保持按钮宽度不变，禁止转圈遮住全文。

### 数值卡 `.card` + `.stat`
- 结构固定：小标签 → 主数值（`--fs-28` 或 `--fs-40`）→ 单位 → 对比/说明。
- 数值卡最多 4 张一行；超过就改成表格。

### 表格 `table`
- 表头 `--fs-11` + 字距 + `--ink-400`，底部 0.5px 描边；**只有一层表头，不做分组表头**。
- 数字列右对齐、等宽；首列左对齐；操作列右对齐且只用文字按钮。
- 分组行（如"早餐 4 项"）用 `--surface-sunken` 底，**该行的数字是组内合计**，不是明细项。
- 空分组不铺破折号，写一行说明 + 动作。

### 状态胶囊 `.pill`
- 变体 `ok / warn / bad / info / flat`；高度 22px，`--fs-11`，不加边框。
- 一句话以内。超过四个字改成 `flat` 中性胶囊或直接写文字。

### 输入 `.field`
- 标签在上（`--fs-11`，`--ink-400`），输入高 40px，圆角 `--r-sm`，聚焦时 `--focus-ring` 描边。
- 可选字段在标签里写"可选"，不要用占位符代替标签。
- 校验错误：输入框描边转 `--danger`，下方 `--fs-11` 说明，**不要只把框变红**。

### 进度条 `.bar`
- 高 8px（粗细两档 8 / 4），底 `--surface-sunken` + 描边，填充 `--accent`；超过目标时填充改 `--ink-900` 并配文字说明。
- 必须有数值标签（`92%`），不能只给条形。

### 空态
- 三段：一句现状 + 一句下一步 + 一个按钮。禁止只放插画不给动作。

### 弹窗
- 宽度 `min(520px, 100%)`；标题 20px；底部主按钮整行；`Esc` 关闭；焦点锁在弹窗内。

### 导航
- 五项主入口 + "工具"分组；当前项用 `--ink-900` 底 + `--accent` 圆点；未实现项禁用并给 `title` 说明。

---

## 7. 图表

- 单色相阶梯 `--chart-1`…`--chart-5` 表达强弱（越深越接近目标），**不用彩虹色**；当前点用 `--accent`。
- 网格线 `--chart-grid`、0.5px，只画横向；**不画纵向网格**。
- 轴标签 `--fs-11` + `tabular-nums`，只保留 3–4 个刻度。
- 折线 1.5px；目标线用 `--chart-4` 虚线；数据点只在端点与当前点画圆。
- 每张图下方必须有一句"怎么读"的说明（`--fs-11`），否则不留。

---

## 8. 动效

- 只有一种时长 `--dur`（120ms）与一条曲线 `--ease`。
- 只做状态过渡：hover、选中、展开、按钮按下。**禁止**入场动画、视差、逐条飞入、骨架屏闪烁。
- 超过 200ms 的动效一律视为错误。

---

## 9. 可访问性硬线

- 正文（14px）对比度 ≥ 4.5:1；大号数值（≥20px）≥ 3:1。
- 所有可交互元素有 `:focus-visible` 焦点环（2px `--focus-ring`，偏移 2px）。
- 不靠颜色单独表意：涨跌、达标、临期都要有文字或符号。
- 键盘可达：弹窗可 `Esc` 关、表单可 `Tab` 走完、表格操作可聚焦。
- 触控目标 ≥ 32×32（桌面也遵守，避免误点）。

## 11. 现状反例清单（改之前先对照）

| 现在的样子 | 问题 | 0.5 的改法 |
| --- | --- | --- |
| 满屏绿色（按钮、链接、图标、进度条全是绿） | 没有层级，强调失效 | 绿色退场，只留一个强调色且只作填充 |
| 卡片有投影、圆角不一 | 像 2018 年后台 | 去阴影，圆角收敛到三档 |
| 提示文字 9px | 小字号发糊 | 最小 11px，靠墨色分层 |
| `.food-page` / `.body-page` 等页面级前缀 | 样式按页面分叉，加一页加一堆 | 组件层统一，页面只做布局 |
| 空餐次铺 5 个 `—` | 视觉噪音 | 一行说明 + 动作 |
| 空页面只有插图 | 不知道下一步做什么 | 现状 + 下一步 + 按钮 |

## 12. 与代码的对应

| 层 | 文件 | 谁可以改 |
| --- | --- | --- |
| 令牌 | `src/styles/tokens.css` | 只有这里能出现色值 |
| 字体 | `src/styles/fonts.css` + `src/assets/fonts/` | 加字重才改 |
| 基础 | `src/styles/base.css` | reset、焦点环 |
| 组件 | `src/styles/components/*.css` | 按本文档实现 |
| 页面 | `src/pages/*` | 只写布局，不写颜色与字号 |

设计守卫（写进测试，M2 起生效）：

1. 除 `tokens.css` 外不得出现 `#RRGGBB` / `rgb()`；
2. `font-size` 不得小于 11px；
3. 不得出现 `box-shadow`；
4. 迁移完成后不得出现 `.food-page` / `.body-page` / `.trends-page` 之类前缀选择器；
5. 关键页截图回归（1440×900 与 1366×768）。

守卫不过 = 不算完成。
