# 轻衡 0.11.0 发布记录

**日期**：2026-10-26 · **分支**：`dev/0.9.4`（工作分支；0.11.0 提交在 main）· **基线**：v0.10.0（main）
**性质**：**大功能版（次版本 0.10→0.11）**——原 0.10.1（更新器三件套）与原 0.12.0（AI 采集）按用户决定并入本版。零 SQL 迁移（`user_version` 仍 14）。

## 本版内容

### 1. 内置食材目录（权威数据，禁止 AI 估算）

- **数据**：USDA FoodData Central SR Legacy（公有领域全量包）采集 **70 项**八大类常见食材（主食谷物/蛋奶/畜禽肉/水产/豆制品/蔬菜/水果/油脂调味），每 100 克可食部口径；**每条带 sourceRef（库名+FDC ID+英文原名）注记，数值全部来自数据原文，缺失标 unknown，不做任何推算**。构建管线 `scripts/build-food-catalog/`（可复跑审计）；后续按人工收录制扩充（用户导出发维护者审核）。
- **启动幂等合并**：按目录版本号只合并一次；用户改过的条目不覆盖；删除登记墓碑单例（升级不复活）；合并失败不阻塞启动。
- **UI**：食材库「全部」分组个人食材在前、内置目录在后（分组头+「内置」徽标）；**修改目录食材=生成个人副本**（可改名，原条目保留）；收藏/归档/删除/食物柜/记餐选择器全兼容。

### 2. AI 采集通道 v1（本地 Ollama，默认关闭）

- 设置 → AI 采集：Ollama 地址（默认 localhost:11434）+ 连接测试 + 模型选择 + 总开关（**默认关**）。
- 饮食页「AI 描述」（开启后显示）：一句话描述 → Ollama（JSON 约束输出，Rust 严格校验+120s 超时）→ **可编辑草稿**（名称/营养行内改）→ 全部加入待确认篮子 → BasketBar 人工核对确认。
- **边界**：营养值一律 `ai_estimate`/low（模型估算，仅供参考），永不直接入账；草稿不持久化（关窗即弃）；解析失败展示错误不静默。
- **隐私**：AI 只连接本机 Ollama，**无任何外网请求**；外网仍仅更新检查。

### 3. 更新器网络三件套（原 0.10.1 并入，v0.10.0 验签失败根因修复）

- **代理跟随**：新增 `get_system_proxy` 命令（winreg 读 WinINET 注册表，唯一新依赖）；偏好「跟随系统代理（默认）/直连」；手动与静默检查同源传 `check({proxy})`。
- **失败一次性提示**：静默检查失败记入偏好，今日页页头细提示条（可关闭，下次失败重现）。
- **错误详情**：检查更新失败展示完整错误+一键复制。

### 4. 镜像后备端点

更新端点在官方 GitHub 后追加 ghfast 社区加速镜像（官方失败按序尝试；minisign 验签保护下载完整性，镜像只能影响可用性不能篡改内容）。镜像实测 200。

## 技术要点

- 新依赖：`winreg`（注册表，零传递）、`reqwest` blocking+json（Ollama HTTP；Tauri 栈已有 reqwest）。`Cargo.toml` 汇总声明。
- `catalogTombstones` 登记为第二单例（SINGLETONS），读写路径对旧信封全兼容（缺失补空数组，读写测试覆盖）。
- 目录合并 hook 挂 `open_database`（仓库就绪才合并；未初始化新库等首次命令建库）。
