内置策划收录的常见食材目录，新装机开箱即用，不用逐个建档。

| 项 | 说明 |
|---|---|
| 内置目录 | 首版收录 **235 项**基础食材（八大类，每类 26–35 项），随版本扩充；来源标记 `catalog`，与个人食材（`personal`）区分 |

### 已知问题（0.11.x 处理）

| 问题 | 说明 |
|---|---|
| 目录数据修正无法传播 | 合并逻辑对已存在的 `catalogId` 一律跳过（为保护用户修改）。因此若某个实例已合并过旧版目录，后续修正的数值不会覆盖它。0.11.0 是目录首个发布版本，新装用户不受影响；开发期已合并过旧目录的实例需单独处理。 |
| 双源未落地 | 香港食物安全中心数据接口逆向成本过高，经用户拍板改为 USDA 单源。若要补中式食材的权威覆盖，可再评估 CFS 或《中国食物成分表》。 |

## 流程承诺（每版不变）

1. 开发迭代 → 侧边栏浏览器用户复查 → 通过后才构建安装包
2. C 级门禁全绿（vitest / tsc / clippy / cargo test / fmt）+ 双主题截图自验
3. 实机验收通过 → 用户确认发布 → 合并 main + tag + Release 三件套
4. 零数据风险：能不迁移就不迁移；要迁移走完整门闩 + 升级前自动备份
