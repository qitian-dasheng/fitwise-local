## 实机验收清单（用户执行，约 25 分钟）

1. **升级路径**：卸载 0.9.2（MSI）→ 确认开始菜单无残留 → 安装 `FitwiseLocal_0.9.3_x64-setup.exe` → 打开应用：**原有记录全部还在**（数据与安装无关的实测证明）
2. **五页走查（浅色）**：今日（指标卡/热量环/14 天柱/餐次常吃）、饮食（常吃栏/日记表/下厨）、身体（速录/趋势图/复盘日历）、运动、食材库（列表/新建表单吸底保存条）
3. **深色主题**：侧栏底部 ◑ 切换 → 重走今日/饮食两页 → 重启应用**记住深色**
4. **今日页行为**：记一餐后「还能吃」区间与热量环变化；确认该日完整；勾选主观状态
5. **设置页**：目标编辑保存；「关于与更新」显示版本 0.9.3，点「检查更新」→ 提示已是最新（联网时）
6. **静默更新演练**（开发者协助）：本地假源指向 0.9.4 假包 → 启动应用 → 自动下载验签 → 确认重启 → 版本变化（或按当次演练说明执行）
7. **数据校验**：设置页领域仓库修订数正常增长；导出 JSON：回执精简形态（文件名+字节+复制哈希+展开详情），`schemaVersion` 仍为 14
8. 性能观察：切页/开弹窗无明显卡顿；深浅切换即时生效
