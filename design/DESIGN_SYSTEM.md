# 轻衡设计系统 · 方向 D（0.9.3 迁移基准）

> **基准样张：`design/prototype/direction-d.html`**（五页全览 + 浅/深双主题切换，2026-10-25 用户定稿）。
> 0.9.3 迁移时，D 的令牌值落入 `src/styles/tokens.css`（唯一真源，`data-theme` 浅/深两套）；在那之前，D 原型文件就是数值参考。本文档只写**规则、用法与禁止项**，不抄色值。

**一句话**：中性克制的界面 + 只在数据层出现的语义色。高级感来自留白、发丝边框和等宽大数字，不来自装饰。

---

## 1. 六条原则

1. **界面全中性，语义色只进数据**。chrome（侧栏/按钮/边框/标题）一律 zinc 中性系；绿/琥珀/红只出现在数值、进度、徽章、图表标注里。正文永不变色。
2. **1px 发丝边框分层，几乎不用阴影**。层级 = 边框 + 底色（bg / card / sunken 三层足够）；阴影只允许 1px 级微投影。
3. **数字是第一公民**。hero 数值 30px 级、tracking-tight、`tabular-nums`；单位与说明用 muted 小一号。翻页数字不许跳。
4. **双主题是一等公民**。每个令牌都成对（light/dark）；深色不是倒色，是另一套校准值（睡前记餐刚需）。禁止只写浅色。
5. **一屏一页，页面不滚**。五主页面 1080p 全屏一屏；超长内容进面板内滚（如食材库网格、全部记录表）。
6. **空态给信息不给破折号**。"尚未记录"配下一步动作；空白柱 = 无记录/热量不全，不画成 0，图下必有一句"怎么读"。

## 2. 令牌角色（值见 D 原型 / 迁移后见 tokens.css）

| 角色 | light | dark | 用途 |
|---|---|---|---|
| `--bg` | 近白灰 | 近黑 | 页面底 |
| `--card` | 白 | 深灰 | 卡片 |
| `--sunken` | 浅灰 | 更深灰 | 选中底、表头、次级面 |
| `--ink` / `--ink-2` | 近黑系 | 米白系 | 主文字 / 次文字 |
| `--muted` / `--faint` | 中灰 / 浅灰 | 中灰 / 暗灰 | 辅助说明 / 仅装饰与占位 |
| `--line` / `--line-2` | 发丝边框两档 | 同 | 卡片边 / hover 加强边 |
| `--primary` / `--primary-ink` | **近黑**（dark 反转为近白） | 反转 | 主按钮、当前柱、强调填充 |
| `--ok` / `--warn` / `--danger`（配 `-soft` 底） | 校准绿/琥珀/红 | 提亮版 | **仅**状态徽章、进度、图表语义 |
| `--ring-track` | 浅灰 | 深灰 | 环与条的底轨 |

- 主按钮近黑（深色下反转近白）——不用彩色做 CTA。
- 一屏语义色不超过两种同时出现；徽章配 `-soft` 底永远可读。
- 强调（`--primary` 填充）一屏最多三处：主按钮、当前导航、当前数据柱。

## 3. 字体

- 字族 Noto Sans SC（随仓库），数字场景强制 `font-variant-numeric: tabular-nums`。
- 三档字重：400 正文 / 500 卡片标题·按钮 / 600-650 页标题·hero 数值。
- 档位：hero 30px（一页最多一个 40px 级）/ 卡片主数值 21–30px / 页标题 17px / 卡片标题 13px / 正文 12.5–13px / 标签与徽章 10.5–11px。**最小 10.5px 只允许图表刻度与徽章**，正文下限 12.5px。
- 标签 = 小号 + muted + 少量字距；标题 tracking 微收（-.01em），hero 数字 -.03em。

---

## 4. 布局与密度

- 驾驶舱骨架：侧栏 216px（品牌 / 五主入口 / 工具组 / 主题切换 / 用户）+ 主区（页头 + 内容）。
- 页头一行：左侧日期+页名，右侧动作（一屏一个 primary）。
- 今日页节奏 = **指标卡行（4 张）→ 主图区（环+宏量 | 趋势柱）→ 底部（明细+常吃）**；其他页同构变体。
- 间距 4 的倍数（12/13 档卡片间距、卡片内 14/16）；圆角三档 6/8–9/12px。
- 图表容器必须有显式高度且内容撑满（见 stylesGuard 教训）；柱状图**永远从底部长起**（flex-column + justify-end，禁止顶垂）。

---

## 5. 组件规范（五态：正常/悬停/焦点/禁用/加载；数据件加空态/错误态）

- **按钮**：默认（card 底+line 边）/ `primary`（primary 底反色字，一屏一个）/ 图标钮。禁用必须配"为什么"提示。
- **指标卡**：小标签行（右挂徽章）→ hero 数值 → 副说明 →（微条/sparkline/点列）。
- **徽章**：`ok/warn/flat` 三态，19px 高，`-soft` 底 + 语义字色，等宽数字。
- **热量环**：底轨 ring-track + primary 弧，环心放大号剩余值；旁配宏量堆叠条（单色三档透明度，不彩虹）+ 图例行。
- **柱状图**：默认柱 line-2 灰、当前柱 primary、目标线 faint 虚线、空白日留空；图下必有口径注释。
- **餐次行/表格**：槽位 muted + 内容 ink-2 + 数值右对齐等宽；未知显示"未知/—"并说明，不为 0。
- **常吃 chips**：名称 + 每份数值两行小卡，hover sunken。
- **表单**：标签在上 10.5px muted，输入 32px 高 line 边；一行多字段布局（身体页速录式）。
- **侧栏**：主项带状态点（active=ok 绿点+sunken 底），工具项带字形图标；**食材库与设置同属「工具」分组**（以 `src/domain/navigation.ts` 的 `toolItems` 为准，2026-10-26 按实际代码修正——此前误写为"第五主入口"）。

---

## 6. 动效与可访问性

- 一种时长（~120ms）一条曲线；只做状态过渡。禁止入场动画、骨架屏闪烁。
- 正文对比 ≥ 4.5:1，大数值 ≥ 3:1（**双主题都要过**）；焦点环全部可交互元素；不靠颜色单独表意；触控目标 ≥ 32px。

## 7. 页面蓝图（五页，均在 D 原型中）

| 页面 | 区块 | 首屏回答 |
|---|---|---|
| **今日** | 指标卡行（还能吃/体重/蛋白/连续）→ 热量环+宏量 \| 14 天柱 → 餐次+常吃 | 我还差多少？下一步点哪？ |
| **饮食** | 日期条+四指标 → 餐次明细 \| 常吃+今日下厨 | 今天吃了什么？全不全？ |

## 8. 迁移与守卫（0.9.3）

1. D 令牌写入 tokens.css 双主题；全局挂 `data-theme`；设置页加主题切换（记住偏好）。
2. 逐页迁移顺序：今日 → 饮食 → 身体 → 运动 → 食材库；每页迁完跑截图自验（浅/深 × 1440×900/1366×768），不等全量完工才看。
3. 守卫（vitest）：① 令牌成对（light/dark 键一致）② 图表容器显式高度（stylesGuard 已有）③ 柱状组件底部对齐（DOM rect 断言，防"顶垂"回归）④ 组件样式里不得出现裸色值（只能引用令牌）⑤ 字号下限。
4. 旧 0.5 体系（绿色 accent、计划/库存/收件箱页）随迁移退役，本文档即唯一现行基准。

## 9. 0.9.4 增补（深色根治与 M2.5 收尾）

1. **颜色唯一真源收紧**：旧恒浅色令牌（`--ink-*` / `--surface*` / `--accent*` / 旧语义色 / `--chart-*`）全部退役，tokens.css 只剩 `--ui-*` 双主题层 + 字体/间距/形状/动效/布局常量。组件样式层（styles.css / ui.css / base.css）禁一切 hex/rgb/rgba（stylesGuard 强制），遮罩走 `--ui-overlay` 令牌。
2. **新令牌**：`--ui-overlay`（浅 rgba(24,24,27,.5) / 深 rgba(0,0,0,.65)，弹窗与抽屉共用）；深色 `--ui-faint` 提亮至 #8b8b94（深卡 ≥5:1，允许承载 10px 级小字）。
3. **设置行模式（SettingsPage）**：页面只留 `.ui-card.settings-menu` 内的 `.settings-row` 列表（图标 + 标题 + 当前值摘要 + ›），点击行打开 `.modal` 承载原卡片全部内容；危险操作（重置）为红行 + 弹窗内勾选两步确认，不再用原生 confirm。
4. **折叠模式**：称重表单（默认收成「记一次称重」入口行 + 最近值副文本，首次使用零记录时展开引导，提交成功自动收起）、复盘提示（`<details>`，有警示 verdict 自动展开）、趋势区空区间（指标行收成一行空态）。
5. **一行卡模式（今日下厨）**：图标 + 名称 + 一行摘要 + 主/次按钮；完整详情让位给管理抽屉——低频信息不占页面高度。
6. **食物柜组件（PantryPanel）**：`.pantry-item` 行 = 名称/数量摘要 + 低存量 `ui-badge warn` + ±快捷增减（步长按单位：g→50、ml→100、计数→1）+ 编辑/移除；低存量整行描边 `--ui-warn`。
7. **图表颜色**：recharts 的 stroke/fill 一律 `var(--ui-*)`（SVG 属性支持 CSS 变量，深浅主题即时切换）；旧 `#e8ebe5`/`#d9a441` 类硬编码已清除。
8. **主题跟随范围**：窗口标题栏随 `setTheme` 同步；窗口主题 API 失败时静默（内容主题不受影响）。
